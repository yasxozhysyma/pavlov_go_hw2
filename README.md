# Система денежных переводов

Учебный проект на Go для перевода денег между пользователями.
Используются структуры, методы, мапы, каналы, горутины и мьютексы.

## Версии

- v1 — структура User, пополнение баланса и снятие средств.
  При нехватке средств Withdraw возвращает ошибку.
- v2 — структура Transaction и система PaymentSystem.
  Пользователи хранятся в мапе, переводы — в очереди.
  Транзакции обрабатываются последовательно.
- v3 — конкурентная обработка тремя воркерами.
  Используются буферизованный канал размером len(ps.TransactionQueue)
  и sync.WaitGroup. Защиты баланса пока нет, возможна гонка данных.
- v4 — sync.Mutex защищает Deposit и Withdraw.
  Добавлен go.mod для запуска в режиме Go-модулей.

## Запуск

Нужен установленный Go.

Клонирование репозитория:

```bash
git clone https://github.com/yasxozhysyma/pavlov_go_hw2.git
cd pavlov_go_hw2
```

Переключение на нужную версию:

```bash
git switch v1
```

Вместо v1 можно указать v2, v3 или v4.

Запуск любой версии:

```bash
go run main.go
```

Для примера в v2–v4 ожидаемые балансы:
Анна — 850, Иван — 650.
В v3 результат может быть некорректным из-за гонки данных.

## Проверка итоговой версии

```bash
git switch v4
CGO_ENABLED=1 go run -race ./...
```

Команда приведена для Linux/WSL.
Детектор гонок требует CGO и C-компилятор.
В Ubuntu компилятор можно установить командой:

```bash
sudo apt install build-essential
```

В v4 программа должна завершаться без предупреждений DATA RACE.
Пользователи и очередь заполняются до запуска воркеров,
итоговые балансы читаются после wg.Wait().

## Ограничения

Balance имеет тип float64 по условиям задания.
Мьютекс защищает операции отдельного пользователя,
но не делает перевод между двумя счетами целиком атомарным.
Порядок обработки транзакций воркерами не гарантирован.
